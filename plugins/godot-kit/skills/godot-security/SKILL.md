# Безопасность Godot

## Что искать (Grep)
- `load(`, `ResourceLoader`, `ResourceSaver` по путям `user://` или внешним: `.tres/.res/.tscn/.scn` могут содержать встроенные скрипты → загрузка файла от пользователя = выполнение кода.
- `Expression`, `GDScript.new()` + `source_code`, `OS.execute`, `OS.create_process`, `OS.shell_open`, `JavaScriptBridge`.
- `str_to_var`/`bytes_to_var` с `allow_objects` = true на недоверенных данных.
- Ключи, токены, пароли в коде и ресурсах (попадут в PCK).
- `@rpc("any_peer"...)` без проверки отправителя и аргументов.

## Правильно
- Сейвы и конфиги — `JSON`/`ConfigFile`/`FileAccess` с проверкой схемы и типов, версия формата, запись во временный файл и переименование, бэкап предыдущего, игра не падает на битом сейве.
- Моды (если будут) — только данные (JSON, изображения, glTF), без скриптов; либо явное предупреждение пользователю.
- Экспорт: debug-флаги и автотест выключены (`OS.is_debug_build()`/фича-теги), шифрование PCK при необходимости (ключ не в репозитории), без лишних файлов (`.godot`, `docs`, `tests` исключены фильтрами экспорта).
- Аддоны и GDExtension — из официальных источников, фиксированная версия, через `skill-vetting`; GDExtension (`.dll/.so`) — высокий риск.
- Steam: ключи и издательские токены — никогда в клиенте.
