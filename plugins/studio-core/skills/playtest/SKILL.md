# Разбор плейтеста

1. Сохрани заметки как есть в `docs/playtests/YYYY-MM-DD.md` (если файл за сегодня есть — допиши; укажи, кто играл и сколько).
2. Разложи замечания: **баг**, **ощущения/управление**, **баланс**, **контент**, **понятность/обучение**, **идея**.
3. Для каждого — конкретное изменение (файл, параметр/логика) и размер: S (минуты), M (час), L (вечер+). Баги — к `qa-tester` (баг-репорт), баланс — к `balance-analyst`.
4. Покажи короткую таблицу и порядок: сначала баги и то, что ломает ощущение игры, потом S-задачи.
5. После согласия — задачи в роадмап, идеи — в бэклог.
6. Не начинай большие изменения без подтверждения.
