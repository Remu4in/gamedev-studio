# Дизайн-сессия

1. Если идея на уровне игры — сначала коротко: жанр, фантазия игрока (кем он себя чувствует), 2–3 референса, платформа и аудитория.
2. Передай работу агенту `game-designer` (через инструмент субагентов), приложив слова пользователя дословно и контекст проекта. Если затронуты мир/уровни — подключи `world-designer`, сюжет и тексты — `narrative-director`, экономика — `balance-analyst`.
3. Покажи пользователю результат коротко: суть, правила, MVP, 2–4 открытых вопроса с вариантами ответов.
4. После ответов — обнови `docs/game_design.md`, запиши решения в журнал решений, идеи «на потом» — в бэклог роадмапа.
5. Предложи следующий шаг: прототип MVP (`/studio-core:prototype`) или включение в план (`/studio-core:plan`).

Правило: вкусовые решения принимает пользователь. Агенты предлагают варианты, а не выбирают за него.
