# План

1. Собери контекст: роадмап, журнал решений, последние плейтесты, открытые баги, git log за последнюю неделю.
2. Вызови агента `producer` с этим контекстом и ограничениями пользователя (сколько времени есть, какие игры параллельно).
3. Покажи план: цель недели, 3–7 задач (размер, кто делает, критерий готовности), что откладываем.
4. После «ок» — обнови роадмап и создай список задач в сессии.
5. Если в плане есть большая механика без дизайна — сначала `/studio-core:design`.
