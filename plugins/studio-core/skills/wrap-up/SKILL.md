# Завершение сессии

1. Если в сессии менялся код и проверка не запускалась — скилл `regression` (минимум юнит-тесты и автотест).
2. Обнови документы (пути — в `CLAUDE.md`, раздел «Студия»):
   - роадмап — отметь сделанное, добавь новое, дата;
   - журнал решений — каждое значимое решение сверху (дата, что, почему, что отложили);
   - дизайн-документ — если менялись механики, контент, числа;
   - `CLAUDE.md` — если менялись архитектура, команды или правила.
3. Git: `git add -A`, коммит на русском (что сделано), `git push`, если настроен remote. Не коммить секреты и большие бинарники вне LFS.
4. Коротко пользователю: что сделали, что проверить руками, с чего начать в следующий раз.
