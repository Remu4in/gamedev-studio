# Старт проекта в студии

Все агенты studio-core читают раздел `## Студия` в `CLAUDE.md` проекта. Этот скилл создаёт его и структуру документов.

## 1. Вопросы (одним сообщением, с вариантами)
- Название и жанр в одной фразе; движок (Godot / Roblox / Unity); платформы.
- Цель: хобби/портфолио/заработок; соло или мультиплеер.
- Что уже есть (код, ассеты, документы).

## 2. Раздел в CLAUDE.md
Добавь (или обнови) в `CLAUDE.md`, не трогая остальное:

```
## Студия
- Игра: <название> — <жанр, одна фраза>. Движок: <…>. Платформы: <…>.
- Наборы: studio-core + <godot-kit | roblox-kit | unity-kit>.
- Язык общения: русский. Тексты в игре: <RU/EN>.
- Команды:
  - запуск: <…>
  - юнит-тесты: <…>
  - автотест/плейтест: <…>
  - нагрузка: <…>
- Документы (если путь отличается от стандартного — укажи здесь):
  дизайн docs/game_design.md · решения docs/decisions.md · роадмап docs/roadmap.md ·
  мир docs/world/ · нарратив docs/narrative/ · арт docs/art/style_guide.md ·
  плейтесты docs/playtests/ · QA docs/qa/ · баланс docs/balance/ · безопасность docs/security/ ·
  релиз docs/release/ · аналитика docs/analytics/ · live-ops docs/liveops/ · техника docs/tech/ ·
  ассеты docs/assets_ledger.md
```

## 3. Структура docs/
Создай только недостающее: `decisions.md` (журнал, новые сверху), `roadmap.md` (Сейчас / Этапы / Бэклог идей), `game_design.md`, `assets_ledger.md` (таблица: файлы, источник, автор, лицензия, AI?, дата, примечание), `qa/bugs.md`, `qa/regression.md`, `playtests/README.md` (шаблон заметок). Остальные папки — по мере надобности.

## 4. Git
Если нет репозитория: `.gitignore` под движок, `.gitattributes` с LFS для бинарных ассетов (glb, fbx, blend, png, jpg, wav, ogg, mp3, rbxm/rbxl), первый коммит. Удалённый репозиторий — приватный, создаёт пользователь.

## 5. Дальше
Предложи: `/studio-core:design` для концепции и `/studio-core:plan` для первого плана.
