# Game feel

Цель: каждое действие игрока даёт мгновенный, читаемый и приятный отклик. Конкретные рецепты для движка — в скилле движка (`godot`, `roblox-gui`/`roblox-luau`); здесь — принципы и порядок.

## Принципы
1. **Слои отклика:** визуал (вспышка, частицы, масштаб) + движение (отбрасывание, тряска, hitstop) + звук. Минимум два слоя на важное событие.
2. **Иерархия силы:** обычное попадание — едва заметно; крит/убийство — сильнее; элита/босс/уровень/покупка — ярко. Если всё «взрывается», ничего не читается.
3. **Короткость:** большинство эффектов 0.05–0.3 с.
4. **Читаемость важнее красоты:** эффекты не закрывают угрозы; лимит частиц и одновременных звуков.
5. **Настройки:** сила тряски и вспышек регулируется (доступность), по умолчанию умеренная.

## Набор приёмов
- Тряска камеры через «trauma» 0..1 с затуханием, смещение ∝ trauma².
- Hitstop 0.04–0.08 с только на сильных событиях, не чаще раза в ~0.3 с.
- Вспышка и «сквош» масштаба 1.0 → 1.15 → 1.0 за 0.1 с при попадании.
- Отбрасывание, зависящее от массы; у боссов ~0.
- Смерть: вспышка + короткие частицы + выпадение награды с «подпрыгиванием».
- Сбор: награда ускоряется к игроку, звук с повышением тона при серии.
- Цифры урона: криты крупнее и другого цвета; в толпе — объединять.
- Звук: 3–5 вариаций или случайный pitch 0.9–1.1; лимит полифонии; частые звуки тише редких.
- UI: кнопки с откликом на наведение и нажатие, анимация появления наград.

## Порядок
1. Узнай (или посмотри плейтест), какие 1–2 момента «не ощущаются».
2. Один слой → пользователь играет → следующий.
3. Все числа эффектов — в одном месте (константы/ресурс настроек).
4. После — `regression`, особенно нагрузка (частицы и звуки при толпе).
