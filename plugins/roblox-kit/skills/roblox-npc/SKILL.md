# NPC и враги в Roblox

## Поведение
- **Конечный автомат:** Idle → Patrol → Chase → Attack → (Flee/Dead). Состояние и переходы — в модуле, параметры (скорость, дистанции, кулдауны) — в конфиге типа врага.
- **Обнаружение:** дистанция → угол обзора → прямая видимость (`workspace:Raycast` с `RaycastParams`, исключая самого NPC). Проверять раз в 0.2–0.5 с, а не каждый кадр.
- **Путь:** `PathfindingService:CreatePath({AgentRadius, AgentHeight, AgentCanJump})` → `ComputeAsync` → точки → `Humanoid:MoveTo`. Пересчитывать при сильном смещении цели или `Path.Blocked`, не каждый кадр. Вблизи цели — прямое движение без пути.
- Все расчёты — **на сервере**; `PrimaryPart:SetNetworkOwner(nil)`, иначе клиент рядом сможет двигать NPC.

## Толпы (волны врагов)
- Один серверный цикл `Heartbeat` обновляет всех врагов батчами (например, 1/4 врагов за кадр), а не скрипт в каждом враге.
- `Humanoid` дорог: для массовых простых врагов — свой контроллер движения (`AlignPosition`/CFrame + `AnimationController`), `Humanoid` — только для сложных.
- Пул врагов: убитого прячем и переиспользуем, а не `Destroy` + `Clone`.
- Лимит одновременно живых врагов на сервер (подбирать по профайлеру), спавн очередью — не больше N в кадр.
- Анимации и эффекты смерти — на клиенте по событию.
- `StreamingEnabled`: далёкие враги не реплицируются — учитывай это в клиентских эффектах.

## Бой
- Урон считает сервер: хитбоксы — `workspace:GetPartBoundsInBox`/`GetPartBoundsInRadius` или рейкаст на сервере; клиент только показывает.
- Телеграф атак (вспышка, круг на земле) перед уроном — честность и читаемость.
- Боссы: фазы по порогам HP, паттерны атак таблицей, иммунитет к отбрасыванию.

## Проверка
Плейтест через Studio MCP с несколькими игроками (Test → Clients and Servers), нагрузка — MicroProfiler при максимальной волне.
