# Аналитика в Roblox

## Встроенное
- **Creator Hub → Analytics:** удержание (D1/D7/D30), вовлечение (сессии, время), монетизация (доход, платящие, ARPPU), аудитория (устройства, страны, возраст), производительность (ошибки, фризы, память).
- Сравнивай с бенчмарками похожих игр, которые показывает Creator Hub.

## AnalyticsService (с сервера)
- `LogOnboardingFunnelStepEvent(player, step, name)` — шаги обучения/первых минут.
- `LogFunnelStepEvent(player, funnelName, funnelSessionId, step, name)` — повторяющиеся воронки (магазин, раунд).
- `LogEconomyEvent(player, flowType, currency, amount, endingBalance, transactionType, itemSku)` — источники (`Source`) и стоки (`Sink`) валют.
- `LogProgressionEvent(...)` — старт/завершение/провал уровней и этапов.
- `LogCustomEvent(player, name, value)` — свои метрики (например, длительность раунда).
- Имена событий и шагов — стабильные, в конфиге; список — в `docs/analytics/events.md`.
- Точные сигнатуры сверяй с документацией (API развивается).

## Минимальный план для запуска
1. Онбординг-воронка: вход → первая награда → первое улучшение → первый раунд → второй раунд.
2. Экономика: каждая валюта — все источники и стоки.
3. Магазин: открыл → посмотрел товар → нажал купить → купил.
4. Причины окончания раунда (смерть, победа, выход).

## Решения
Одна гипотеза за раз, достаточная выборка, сравнение до/после или A/B (эксперименты Creator Hub для превью/иконок; для геймплея — свой флаг по `UserId`).
