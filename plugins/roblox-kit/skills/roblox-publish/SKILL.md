# Публикация в Roblox

Требования платформы меняются — сверяйся с актуальной документацией Creator Hub.

## Перед первой публикацией
- [ ] Анкета **Maturity & Compliance** заполнена честно.
- [ ] Название, описание (что делать в игре в 1–2 строках), жанр, иконка, 3+ превью (миниатюры), при желании видео.
- [ ] Настройки: размер сервера, разрешённые устройства (телефон, планшет, ПК, консоль), чат, доступ к API Services, `LoadStringEnabled` выключен, `HttpEnabled` только при необходимости.
- [ ] Геймпассы и Developer Products созданы, ID в конфиге, покупки проверены в Studio.
- [ ] Права на все ассеты (`docs/assets_ledger.md`), музыка — только с правами для Roblox.

## Перед каждым обновлением
- [ ] Регрессия и плейтест через Studio MCP: нет ошибок в консоли сервера и клиента.
- [ ] Тест с несколькими клиентами (Test → Clients and Servers) и на мобильном (Device Simulator + реальное устройство).
- [ ] Сохранения: старые профили грузятся (миграции), нет потерь данных.
- [ ] Свежий отчёт `appsec-reviewer` по изменениям (RemoteEvents, покупки, новые ассеты).
- [ ] Патчноуты и окно «что нового».
- [ ] План отката: предыдущая версия места в истории версий (Version History → Restore).

## После публикации
- Перезапуск серверов для применения (Shutdown All Servers / Migrate to Latest Update).
- 24–72 часа: ошибки в Creator Hub (Error Report), удержание и покупки — с `analytics-engineer`.
