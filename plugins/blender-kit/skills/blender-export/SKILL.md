# Экспорт из Blender в движок

Скрипт: `tools/blender/bk_export.py` (`engine`, `out_dir` — абсолютный путь, папка должна существовать; `objects`, `name`, `profile`). Работает на временных копиях: сцена после экспорта не меняется. Перед экспортом — `bk_validate.py` с тем же `engine` без FAIL.

| | Godot 4 | Unity | Roblox |
|---|---|---|---|
| Формат | `.glb` | `.fbx` | `.glb` |
| Оси / масштаб | glTF: +Y вверх, метры | −Z вперёд, Y вверх, FBX Units Scale, метры | метры; в импортёре **Scale Unit = Meter** |
| LOD | генерирует импортёр Godot | меши `<имя>_LOD0.._LODn` → LODGroup при импорте | делает движок |
| Коллизия | узел `<имя>-convcolonly` (выпуклая оболочка) или `-colonly` (бокс) → StaticBody3D | отдельный меш `<имя>_collider`, коллайдер вешается в Unity (по умолчанию выключено) | `CollisionFidelity` в Studio (Box/Hull) |
| Лимиты | — | — | **20 000 треугольников на меш** (иначе импортёр сам упростит), ≤ 4 костей на вершину |

Скрипт сам пропускает LOD, который не уменьшает меш или искажает габариты (low-poly из отдельных деталей), и пишет об этом в `warnings`.

## Godot 4 (вместе с `godot-kit:godot`)
- `.glb` положить в папку ассетов проекта → импорт (`--headless --path . --import` или редактор).
- Суффиксы имён работают, если в импорте не выключены `nodes/use_node_type_suffixes`/`use_name_suffixes`.
- Анимации: клипы с `loop`/`cycle` в начале или конце имени импортируются зацикленными.
- Проверка: сцена открывается, масштаб рядом с CharacterBody3D игрока, у `-convcolonly` есть StaticBody3D + CollisionShape3D, материал с текстурой палитры.

## Unity (вместе с `unity-kit:unity`)
- Import Settings → Model: Scale Factor 1, **Convert Units** вкл, **Bake Axis Conversion** вкл (уходит −90° по X на корне).
- Rig: персонажи Humanoid/Generic по проекту; анимации — отдельные FBX или клипы.
- Materials: Extract Textures/Materials при необходимости; палитровая текстура — Filter Mode **Point**, без мип-сглаживания цветов (иначе цвета палитры смешаются на расстоянии).
- Проверка: Transform на корне = (0,0,0)/(0,0,0)/(1,1,1), размер рядом с кубом 1×1×1, LODGroup создан.

## Roblox (вместе с `roblox-kit:roblox-mcp`)
- Studio → Import 3D → **Scale Unit = Meter** (по умолчанию Studs — модель будет не того размера). Масштаб в Studio не подгонять руками — переимпортировать с правильным Scale Unit.
- Проверь размер рядом со стандартным Part и аватаром.
- Меш > 20k треугольников — вернись к `bk_normalize.py` (категория/бюджет), не полагайся на автоупрощение.
- `CollisionFidelity`: Box — дешевле всего, Hull — большинство пропсов, PreciseConvexDecomposition — только когда нужно.
- Через Studio MCP вставленный ассет — в `docs/assets_ledger.md`.

## Десктоп / другие движки
`engine: "gltf"` (GLB без суффиксов) или `"fbx"` (настройки как для Unity). Unreal — FBX, коллизии `UCX_<имя>`; профиль не входит в v0.1.

## Если что-то не так
| Симптом | Причина | Что сделать |
|---|---|---|
| В 100 раз больше/меньше | единицы | Unity: Convert Units; Roblox: Scale Unit = Meter; в Blender — `bk_validate` (tiny/huge) |
| Лежит на боку / смотрит назад | поворот не применён | `bk_normalize.py` заново; модель должна смотреть в −Y Blender |
| Без текстуры | текстура не упакована | `bk_validate` (image_unsaved); палитра упаковывается автоматически |
| Розовый/серый материал | процедурные узлы шейдера | запечь в текстуру или перекрасить в палитру |
| Нет коллизии в Godot | суффиксы выключены в импорте | включить `use_node_type_suffixes` |
