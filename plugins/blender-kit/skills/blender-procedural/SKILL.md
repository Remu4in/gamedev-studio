# Процедурные ассеты

Процедурное — самый надёжный способ закрыть дыры: ассет **в стиле по построению** (палитра, фаска и шейдинг берутся из профиля), бесплатный, повторяемый по seed, без вопросов лицензии.

Скрипт: `tools/blender/bk_generators.py` (как запускать — `blender-assets`).

## Генераторы v0.1
| kind | Для чего | Главные opts (по умолчанию) | Роли палитры |
|---|---|---|---|
| `crate` | ящик с рамой и диагональю | size 0.8, frame 0.08 | wood, wood_dark |
| `barrel` | бочка с обручами | height 1.0, radius 0.32, bulge 0.06, segments 10 | wood, metal |
| `rock` | камень, валун | size 1.0, detail 1, roughness 0.25, flatten 0.6 | stone |
| `fence` | секция забора | length 2.0, height 1.0, posts 3, rails 2 | wood |
| `wall` | модуль стены, проём none/door/window | width 4, height 3, thickness 0.3, opening | stone, stone_dark |
| `floor_tile` | плитка пола под сетку | size 2.0, thickness 0.15 | stone |
| `pillar` | колонна с базой и капителью | height 3, radius 0.25, segments 8 | stone, stone_dark |
| `tree` | дерево round/pine | height 4, style, crown 1.2, layers 3 | bark, foliage |
| `crystal` | друза кристаллов | height 1.2, count 5, spread 0.35 | crystal |
| `stairs` | лестничный пролёт | width 1.5, steps 6, step_h 0.18, step_d 0.3 | stone |

Роль `*_dark` без своего цвета в палитре = базовая роль, затемнённая. Нет роли в палитре → серый + предупреждение: добавь роль в профиль (с согласия пользователя).

## Порядок
1. Сверь размеры с сеткой уровня (`docs/world/`, скилл `studio-core:world-designer`): модули стен и плитки — кратны шагу сетки, высота двери — под рост персонажа.
2. `bk_generators.py` с `kind`, `name`, `seed`, `variants` (3–6 для разнообразия), `opts`. Параметры `bevel`, `shading`, `roughness` берутся из профиля.
3. Покажи варианты через `bk_preview.py` рядом с эталонами — пусть пользователь выберет лучшие seed.
4. Выбранные → `bk_normalize.py` (`recolor: "palette"` собирает всё в общий атлас) → `bk_validate.py` → `bk_export.py`.
5. В `docs/assets_ledger.md`: источник «процедурный blender-kit», `kind` + `seed` + `opts` — ассет можно пересобрать.

## Свой генератор
Нужен новый тип (сундук, фонарь, мост) — добавь функцию в **проектную** копию `tools/blender/bk_generators.py`:
- сигнатура `gen_<kind>(bm, o, rng)`; геометрия от `z=0` вверх, центр по X/Y в нуле, метры;
- детали — через `add_box` / `add_cyl` / `add_ico` с индексом роли (0, 1, … из `roles`);
- случайность — только через `rng` (повторяемость по seed);
- впиши `kind` в `GEN_DEFAULTS`, `GENERATORS` и в `build()` (явный `if/elif`: safe mode не пропускает вызов функции из словаря);
- без `lambda`, классов, `open`, `os` — иначе safe mode отклонит скрипт.
Удачный генератор предложи перенести в каталог `gamedev-studio` (отдельный коммит).

## Когда процедурное не подходит
Органика с узнаваемой формой (персонажи, животные, сложные механизмы) → `blender-ai-3d` или CC0. Процедурное хорошо для пропсов, модулей уровня, растительности и россыпей.
