# UI в Unity (каркас)
- UI Toolkit (UXML/USS) для меню и экранов; uGUI — если нужен UI в мире или готовые решения.
- Canvas Scaler (Scale With Screen Size), безопасные зоны (`Screen.safeArea`) для мобильных.
- Input System (новый) — действия для клавиатуры, геймпада и тача одним набором.
- Тексты — через Localization package, не строками в коде.
- Отклик и анимации — по `game-feel`.
