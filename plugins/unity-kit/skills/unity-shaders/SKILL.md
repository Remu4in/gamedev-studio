# Шейдеры Unity (каркас)
- URP по умолчанию для инди и мобильных; Shader Graph для большинства задач, HLSL — когда граф не справляется.
- Стилизация: toon-освещение (ramp), контуры (inverted hull или постобработка), dither-прозрачность.
- VFX Graph — массовые GPU-частицы (ПК/консоли); Particle System — мобильные.
- Варианты шейдеров держать под контролем (shader stripping), иначе долгая сборка и память.
- Стиль — по стайлгайду (`art-direction`).
