# Addressables (каркас)
- Загрузка по адресу/лейблу асинхронно; каждое `LoadAssetAsync` — парный `Release`.
- Группы по сценам/уровням и частоте изменений; локальные vs удалённые.
- Анализ дубликатов (Analyze tool), профайлер памяти.
- Удалённый контент — только с подписью/HTTPS, источник под контролем (см. `appsec-reviewer`).
